## Title

AR Dental Care — Doctor Appointments & Prescription Pad

## Short pitch

Self-hosted dental clinic system: doctor dashboard, public appointment link with QR, Bangladesh phone validation, pad-style prescriptions with medicine search, and shareable patient Rx links. Laravel API + React SPA, mobile-ready tokens.

## Who it’s for

Solo dentists / small dental clinics in Bangladesh (and similar markets) who need appointments + e-prescriptions without a heavy HIS.

## Stack (declare on listing)

- Frontend: React 19 + Vite + Tailwind + React Router
- Backend: Laravel 13 + Sanctum
- Database: MySQL 8 / MariaDB / SQLite (local)
- Auth: Bearer tokens (SPA + future mobile)
- Built with: Cursor / Composer

## Features to list

- Doctor register/login (email or BD phone) with OTP / email verification
- Demo account for instant trial
- Dashboard (stats, chart, today’s patients, appointment QR)
- Appointment list + status actions
- Availability / appointment configuration
- Clinic profile (logo, BMDC, hours) drives prescription header
- Prescription pad (C/C, O/E, advice + medicine popup)
- Share Rx via email, WhatsApp, public link
- Public appointment calendar (no patient login)
- Email + SMS confirmation hooks (log drivers out of the box)
- Optional Oushodh medicine sync
